# Codex 学習デモシステム（PHP / JS / CSS）

生成AIツールを学習中の初心者チーム向けに、Codex の代表機能を説明・体験できるローカルデモです。

## 対応機能
- コード生成
- 既存コードの解析
- バグ修正
- リファクタリング
- テストデータ作成

## Codex作 ツール
- `index.php` の「Codex作 ツール」ボタンからモーダルを開いてツール選択可能
- 電卓: 実装済み（`tools/calculator.php` へ遷移）
  - 四則演算（+ / - / * / /）
  - パーセント計算（%）
  - AC（全クリア）/ ⌫（1文字削除）
- メモ帳: ボタンのみ（準備中・遷移なし）
- カレンダー: ボタンのみ（準備中・遷移なし）

## 技術構成
- PHP: 画面テンプレート生成
- JavaScript: 機能切替とデモ出力、モーダル制御、電卓ロジック
- CSS: レイアウトとスタイル
- DB接続: なし
- 外部API接続: なし

## 起動方法
```bash
php -S localhost:8000
```

ブラウザで `http://localhost:8000/index.php` を開いてください。
